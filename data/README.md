# Input data

Place these four Excel files in this folder (names must match exactly):

| File | Contents |
|---|---|
| `RSVA_importsfromregionstoNic.xlsx` | RSV-A introductions into Nicaragua |
| `RSVA_exports_Nicto otherregions.xlsx` | RSV-A exports from Nicaragua |
| `RSVB_regionstonicaragua.xlsx` | RSV-B introductions into Nicaragua |
| `RSVB_nicaraguatoregions.xlsx` | RSV-B exports from Nicaragua |

Each file is an event list: column 1 = event number, plus one column of region names (e.g. `South America`, `North America`, `Europe`).

> If these data are unpublished or restricted, do not commit them. Add `data/*.xlsx` to `.gitignore` and share them through an approved channel instead.
